Exercise 1. Determinant of a 2×2 Matrix

The question

Compute

$$\det\begin{pmatrix}3&-2\\5&4\end{pmatrix},\qquad \det\begin{pmatrix}1&7\\2&14\end{pmatrix}.$$

Which matrix is invertible? Justify the answer.

Before calculating: what idea do we need?

For a $2\times2$ matrix

$$\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc.$$

The determinant tells us whether the matrix loses information:

  • $\det\neq0$: the matrix is invertible,
  • $\det=0$: the matrix is singular. Its rows (and columns) are dependent, and it cannot be undone.

The reason is the inverse formula $\dfrac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$. It requires dividing by the determinant.

1. First matrix

$$\det\begin{pmatrix}3&-2\\5&4\end{pmatrix}=3\cdot4-(-2)\cdot5=12+10=22.$$

2. Second matrix

$$\det\begin{pmatrix}1&7\\2&14\end{pmatrix}=1\cdot14-7\cdot2=14-14=0.$$

3. Which one is invertible?

  • The first matrix has $\det=22\neq0$, so it is invertible.
  • The second matrix has $\det=0$, so it is not invertible.

4. Why the second one fails

The second row is twice the first row:

$$(2,14)=2\cdot(1,7).$$

The two rows carry the same information. Geometrically, the matrix squashes the whole plane onto a single line (every image is a multiple of $(1,2)^T$). Many different points land on the same point, so the map cannot be reversed.

5. Quick verification

For the first matrix, the inverse formula gives

$$A^{-1}=\frac{1}{22}\begin{pmatrix}4&2\\-5&3\end{pmatrix}.$$

Check:

$$\begin{pmatrix}3&-2\\5&4\end{pmatrix}\begin{pmatrix}4&2\\-5&3\end{pmatrix}=\begin{pmatrix}12+10&6-6\\20-20&10+12\end{pmatrix}=\begin{pmatrix}22&0\\0&22\end{pmatrix}=22I.$$

After dividing by $22$ we get $I$. ✓

6. A concrete example

For the second matrix, two different vectors give the same result:

$$\begin{pmatrix}1&7\\2&14\end{pmatrix}\begin{pmatrix}7\\0\end{pmatrix}=\begin{pmatrix}7\\14\end{pmatrix}=\begin{pmatrix}1&7\\2&14\end{pmatrix}\begin{pmatrix}0\\1\end{pmatrix}.$$

From the output $(7,14)^T$ we cannot tell which input we started with. That is exactly what "not invertible" means.

How I would explain this in class

For a $2\times2$ matrix the determinant is $ad-bc$. The first one is $12+10=22$, which is not zero, so it is invertible. The second one is $14-14=0$, because its second row is twice the first. Its rows are dependent, the plane is squashed onto a line, and the matrix cannot be inverted.

Exercise 2. Determinant of a 3×3 Matrix

The question

For

$$A=\begin{pmatrix}1&2&-1\\0&3&4\\2&1&5\end{pmatrix}$$

compute $\det A$ using Sarrus' rule, then perform one simple check using a determinant property.

Before calculating: what idea do we need?

Sarrus' rule works only for $3\times3$ matrices. Copy the first two columns to the right of the matrix:

$$\begin{array}{ccc|cc}a&b&c&a&b\\d&e&f&d&e\\g&h&i&g&h\end{array}$$

Then

$$\det A=\underbrace{aei+bfg+cdh}_{\text{down-right diagonals}}-\underbrace{(ceg+afh+bdi)}_{\text{down-left diagonals}}.$$

For the check we use a different property: adding a multiple of one row to another does not change the determinant. This lets us create zeros and recompute quickly.

1. Sarrus' rule

$$\begin{array}{ccc|cc}1&2&-1&1&2\\0&3&4&0&3\\2&1&5&2&1\end{array}$$

Down-right diagonals:

$$1\cdot3\cdot5+2\cdot4\cdot2+(-1)\cdot0\cdot1=15+16+0=31.$$

Down-left diagonals:

$$(-1)\cdot3\cdot2+1\cdot4\cdot1+2\cdot0\cdot5=-6+4+0=-2.$$

Therefore

$$\det A=31-(-2)=33.$$

2. Check using a row operation

Apply $R_3\leftarrow R_3-2R_1$, which does not change the determinant:

$$R_3-2R_1=(2,1,5)-(2,4,-2)=(0,-3,7),\qquad A'=\begin{pmatrix}1&2&-1\\0&3&4\\0&-3&7\end{pmatrix}.$$

Now the first column is $(1,0,0)^T$, so expanding along it leaves one $2\times2$ determinant:

$$\det A'=1\cdot\det\begin{pmatrix}3&4\\-3&7\end{pmatrix}=21-(-12)=33.\ ✓$$

3. Meaning

$\det A=33\neq0$, so $A$ is invertible. Geometrically, $A$ maps the unit cube to a parallelepiped of volume $33$.

4. Common mistake

The minus sign in front of the second group of diagonals is often forgotten, or the $-1$ entry loses its sign. Here, forgetting the outer minus would give $31+(-2)=29$ instead of $33$. The independent check catches this kind of error.

5. A concrete example

Sarrus' rule does not extend to $4\times4$ matrices. For larger matrices we use row operations (as in the check above) or cofactor expansion.

How I would explain this in class

I write the first two columns again to the right, add the three down-right diagonal products ($31$) and subtract the three down-left ones ($-2$), so $\det A=33$. To check, I subtract twice row 1 from row 3. That doesn't change the determinant and creates a zero, and the reduced $2\times2$ determinant is again $33$.

Exercise 3. Swapping Two Rows

The question

For

$$A=\begin{pmatrix}1&2&0\\0&3&1\\2&1&1\end{pmatrix}$$

compute $\det A$. Form $B$ by swapping the first and second rows of $A$, predict $\det B$ using a determinant property, and verify the prediction by calculation.

Before calculating: what idea do we need?

Two tools:

  1. Cofactor expansion along the first row: $$\det A=a_{11}M_{11}-a_{12}M_{12}+a_{13}M_{13},$$ where $M_{1j}$ is the $2\times2$ determinant left after deleting row 1 and column $j$. The signs alternate $+,-,+$.
  2. Row swap property: swapping two rows changes the sign of the determinant but not its absolute value. Geometrically, a swap flips the orientation (like a mirror) but keeps the volume.

1. Compute $\det A$

$$\det A=1\cdot\det\begin{pmatrix}3&1\\1&1\end{pmatrix}-2\cdot\det\begin{pmatrix}0&1\\2&1\end{pmatrix}+0\cdot(\dots)$$
$$=1\cdot(3-1)-2\cdot(0-2)+0=2+4=6.$$

2. Form $B$ and predict

$$B=\begin{pmatrix}0&3&1\\1&2&0\\2&1&1\end{pmatrix}.$$

$B$ is obtained from $A$ by one row swap, so the prediction is

$$\det B=-\det A=-6.$$

3. Verify by calculation

$$\det B=0\cdot\det\begin{pmatrix}2&0\\1&1\end{pmatrix}-3\cdot\det\begin{pmatrix}1&0\\2&1\end{pmatrix}+1\cdot\det\begin{pmatrix}1&2\\2&1\end{pmatrix}$$
$$=0-3\cdot(1-0)+1\cdot(1-4)=-3-3=-6.\ ✓$$

The prediction is confirmed.

4. Why a swap changes the sign

In every term of the determinant expansion, each row contributes one entry according to a permutation of the columns. Swapping two rows composes every permutation with a transposition, which changes the parity of the corresponding permutation in the determinant expansion and reverses its coefficient sign. Geometrically, the volume spanned by the rows stays the same, but the orientation flips.

Consequence: if two rows are equal, swapping them changes nothing, but must change the sign. So $\det=-\det$, which forces $\det=0$.

5. Quick verification

Check $\det A$ with Sarrus' rule:

$$(1\cdot3\cdot1+2\cdot1\cdot2+0)-(0+1\cdot1\cdot1+2\cdot0\cdot1)=(3+4)-1=6.\ ✓$$

6. A concrete example

Swapping twice returns $A$, and the sign flips twice: $(-1)^2\cdot6=6$. In general, $k$ swaps multiply the determinant by $(-1)^k$.

How I would explain this in class

Expanding along the first row gives $\det A=2+4=6$. Swapping two rows only flips the sign, so I predict $\det B=-6$. Computing $\det B$ directly gives $-3-3=-6$, as predicted. A swap keeps the volume but reverses the orientation.

Exercise 4. Triangular Matrix

The question

Without expanding the determinant, compute

$$\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}.$$

State the rule for an arbitrary triangular matrix and explain it using this example.

Before calculating: what idea do we need?

A matrix is upper triangular if all entries below the main diagonal are zero (lower triangular: all above are zero).

Rule: the determinant of a triangular matrix is the product of its diagonal entries:

$$\det\begin{pmatrix}a_{11}&*&*\\0&a_{22}&*\\0&0&a_{33}\end{pmatrix}=a_{11}a_{22}a_{33}.$$

This is the reason why elimination is used to compute determinants: it turns any matrix into a triangular one.

1. Apply the rule

$$\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}=2\cdot(-3)\cdot7=-42.$$

2. Why the rule works (explained on this example)

Expand along the first column. It has only one non-zero entry, the $2$:

$$\det=2\cdot\det\begin{pmatrix}-3&5\\0&7\end{pmatrix}.$$

The smaller matrix is again triangular. Expanding along its first column:

$$\det\begin{pmatrix}-3&5\\0&7\end{pmatrix}=-3\cdot7-5\cdot0=-21.$$

So $\det=2\cdot(-21)=-42$. At each step only the diagonal entry survives, because everything below it is zero. The entries above the diagonal ($4,1,5$) never matter.

Another view: in every term of the determinant we must take exactly one entry from each row and each column. The only choice that avoids every zero below the diagonal is the diagonal itself.

3. Meaning

  • The matrix is invertible exactly when no diagonal entry is zero. Here all three are non-zero, so it is invertible.
  • The negative sign means the transformation reverses orientation (because of the $-3$). The volume scaling factor is $|{-42}|=42$.

4. Quick verification

Sarrus' rule: down-right diagonals $2\cdot(-3)\cdot7+4\cdot5\cdot0+1\cdot0\cdot0=-42$. Down-left diagonals: $1\cdot(-3)\cdot0+2\cdot5\cdot0+4\cdot0\cdot7=0$. So $\det=-42-0=-42$. ✓

5. A concrete example

If we change the $7$ to $0$:

$$\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&0\end{pmatrix}=2\cdot(-3)\cdot0=0.$$

This makes sense, because the last row is the zero row, so the matrix is singular.

How I would explain this in class

For a triangular matrix I just multiply the diagonal: $2\cdot(-3)\cdot7=-42$. The reason is that expanding along the first column, only the diagonal entry has a non-zero value, and the smaller matrix is triangular again. The entries above the diagonal never matter. So a triangular matrix is invertible exactly when there is no zero on the diagonal.

Exercise 5. Row Operations

The question

For

$$A=\begin{pmatrix}1&2&3\\2&1&0\\-1&4&2\end{pmatrix}$$

find $\det A$ by simplifying the matrix with row operations. At each step, state whether and how the determinant changes.

Before calculating: what idea do we need?

How each elementary row operation affects the determinant:

OperationEffect on $\det$
$R_i\leftarrow R_i+cR_j$ (add a multiple of another row)no change
$R_i\leftrightarrow R_j$ (swap)multiply by $-1$
$R_i\leftarrow cR_i$ (scale a row)multiply by $c$

Plan: use only "add a multiple" operations to reach a triangular matrix (no change at all), then multiply the diagonal (Exercise 4).

1. Clear the first column

$R_2\leftarrow R_2-2R_1$: $(2,1,0)-(2,4,6)=(0,-3,-6)$. No change to $\det$.

$R_3\leftarrow R_3+R_1$: $(-1,4,2)+(1,2,3)=(0,6,5)$. No change to $\det$.

$$A_1=\begin{pmatrix}1&2&3\\0&-3&-6\\0&6&5\end{pmatrix},\qquad \det A_1=\det A.$$

2. Clear the second column

$R_3\leftarrow R_3+2R_2$: $(0,6,5)+(0,-6,-12)=(0,0,-7)$. No change to $\det$.

$$A_2=\begin{pmatrix}1&2&3\\0&-3&-6\\0&0&-7\end{pmatrix},\qquad \det A_2=\det A.$$

3. Read off the determinant

$A_2$ is upper triangular, so

$$\det A=\det A_2=1\cdot(-3)\cdot(-7)=21.$$

4. Summary of the steps

StepOperationFactorRunning $\det$ relation
1$R_2\leftarrow R_2-2R_1$$1$$\det A_{\text{new}}=\det A$
2$R_3\leftarrow R_3+R_1$$1$$\det A_1=\det A$
3$R_3\leftarrow R_3+2R_2$$1$$\det A_2=\det A$

No swaps and no scalings were needed, so no correction factor appears.

5. Why "add a multiple" does not change the determinant

The determinant is linear in each row, so

$$\det(\dots,R_i+cR_j,\dots)=\det(\dots,R_i,\dots)+c\,\det(\dots,R_j,\dots).$$

The last determinant has two equal rows ($R_j$ appears twice), so it is $0$. Geometrically, this is a shear, which slides the shape without changing its volume.

6. Quick verification

Cofactor expansion along the first row of the original matrix:

$$\det A=1(1\cdot2-0\cdot4)-2(2\cdot2-0\cdot(-1))+3(2\cdot4-1\cdot(-1))=2-8+27=21.\ ✓$$

7. A concrete example

If at step 3 we had instead scaled $R_2$ by $-\tfrac13$ to get a pivot $1$, the determinant would have been multiplied by $-\tfrac13$, and we would need to multiply back by $-3$ at the end. Avoiding scaling keeps the bookkeeping simple.

How I would explain this in class

I use only operations of the type "add a multiple of one row to another", because they don't change the determinant. After three such steps the matrix is upper triangular with diagonal $1,-3,-7$, so $\det A=21$. A direct cofactor expansion gives the same value, $2-8+27=21$.

Exercise 6. Parameter and Invertibility

The question

For

$$A(t)=\begin{pmatrix}t&1\\2&t\end{pmatrix}$$

find all values of $t$ for which the matrix is not invertible, and explain how the answer is related to the determinant being zero.

Before calculating: what idea do we need?

A square matrix is invertible if and only if its determinant is non-zero. So instead of trying to invert $A(t)$ for every $t$, we compute $\det A(t)$ as a function of $t$ and find where it is zero.

1. Compute the determinant

$$\det A(t)=t\cdot t-1\cdot2=t^2-2.$$

2. Find the forbidden values

$$t^2-2=0\iff t^2=2\iff t=\pm\sqrt2.$$

So $A(t)$ is not invertible exactly for

$$t=\sqrt2\quad\text{or}\quad t=-\sqrt2,$$

and it is invertible for all $t\in\mathbb{R}\setminus\{-\sqrt2,\sqrt2\}$.

3. The inverse for allowed values

$$A(t)^{-1}=\frac{1}{t^2-2}\begin{pmatrix}t&-1\\-2&t\end{pmatrix}.$$

The factor $\frac{1}{t^2-2}$ shows directly why $t=\pm\sqrt2$ is excluded: we would divide by zero.

4. Why the excluded values fail

Take $t=\sqrt2$:

$$A(\sqrt2)=\begin{pmatrix}\sqrt2&1\\2&\sqrt2\end{pmatrix},\qquad (2,\sqrt2)=\sqrt2\cdot(\sqrt2,1).$$

The second row is a multiple of the first, so the rows are dependent. For $t=-\sqrt2$: $(2,-\sqrt2)=-\sqrt2\cdot(-\sqrt2,1)$, again dependent. In both cases the plane is squashed onto a line, and the map cannot be undone.

5. Quick verification

$$\begin{pmatrix}t&1\\2&t\end{pmatrix}\begin{pmatrix}t&-1\\-2&t\end{pmatrix}=\begin{pmatrix}t^2-2&-t+t\\2t-2t&-2+t^2\end{pmatrix}=(t^2-2)I.$$

After dividing by $t^2-2$ we get $I$, which confirms the inverse formula. ✓

6. A concrete example

For $t=2$: $\det=2$, and

$$A(2)=\begin{pmatrix}2&1\\2&2\end{pmatrix},\qquad A(2)^{-1}=\frac12\begin{pmatrix}2&-1\\-2&2\end{pmatrix}=\begin{pmatrix}1&-\tfrac12\\-1&1\end{pmatrix}.$$

How I would explain this in class

The matrix is invertible exactly when the determinant isn't zero. Here $\det A(t)=t^2-2$, which is zero for $t=\pm\sqrt2$. At those values the rows are multiples of each other, so the matrix is singular. For every other $t$ the inverse is $\frac{1}{t^2-2}\begin{pmatrix}t&-1\\-2&t\end{pmatrix}$.

Exercise 7. Using Properties Instead of Recomputing

The question

For a $3\times3$ matrix with $\det A=-4$, compute

$$\det(2A),\qquad \det(A^T),\qquad \det(A^2),\qquad \det(-A),$$

justifying each answer with the appropriate property.

Before calculating: what idea do we need?

We don't know the entries of $A$, so we cannot compute anything directly. We must use properties instead:

PropertyFormula ($n\times n$)
Scaling$\det(cA)=c^n\det A$
Transpose$\det(A^T)=\det A$
Product$\det(AB)=\det A\cdot\det B$

The scaling rule is the one most often done wrong: $cA$ multiplies every row by $c$, and each row contributes one factor $c$. With $n$ rows we get $c^n$, not $c$.

1. $\det(2A)$

$A$ is $3\times3$, so all three rows are multiplied by $2$:

$$\det(2A)=2^3\det A=8\cdot(-4)=-32.$$

2. $\det(A^T)$

Transposing does not change the determinant (rows and columns play symmetric roles):

$$\det(A^T)=\det A=-4.$$

3. $\det(A^2)$

By the product rule:

$$\det(A^2)=\det(A\cdot A)=\det A\cdot\det A=(-4)^2=16.$$

4. $\det(-A)$

$-A=(-1)A$, so by the scaling rule with $n=3$:

$$\det(-A)=(-1)^3\det A=-1\cdot(-4)=4.$$

5. Summary and meaning

ExpressionPropertyValue
$\det(2A)$$c^n\det A$$-32$
$\det(A^T)$transpose invariance$-4$
$\det(A^2)$product rule$16$
$\det(-A)$$(-1)^n\det A$$4$

Geometric reading: $A$ scales volume by $4$ and flips orientation. $2A$ also doubles every length, which multiplies volume by $2^3=8$. $A^2$ flips orientation twice, so the sign becomes positive. $-A=(-I)A$ applies $A$ and then a point reflection $-I$; the reflection $-I$ has determinant $(-1)^3=-1$ in dimension 3, so composing it with $A$ changes the determinant from $-4$ to $+4$.

6. Quick verification with a concrete matrix

Take $A=\operatorname{diag}(-4,1,1)$, so $\det A=-4$. Then

  • $2A=\operatorname{diag}(-8,2,2)$, $\det=-32$. ✓
  • $A^T=A$, $\det=-4$. ✓
  • $A^2=\operatorname{diag}(16,1,1)$, $\det=16$. ✓
  • $-A=\operatorname{diag}(4,-1,-1)$, $\det=4$. ✓

7. A concrete example of the common mistake

Writing $\det(2A)=2\det A=-8$ would be wrong. For a $3\times3$ matrix, scaling by $2$ doubles length, width and height, so volume grows by $8$, not $2$.

How I would explain this in class

I can't compute $A$, so I use properties. Multiplying a $3\times3$ matrix by $2$ multiplies each of the three rows by $2$, so $\det(2A)=8\cdot(-4)=-32$. Transposing doesn't change the determinant, so $\det A^T=-4$. The product rule gives $\det A^2=16$, and $\det(-A)=(-1)^3(-4)=4$.

Exercise 8. Determinant of a Product

The question

Let $A,B$ be square matrices with $\det A=3$ and $\det B=-5$. Compute $\det(AB)$, $\det(BA)$ and, if it exists, $\det(A^{-1}B)$. Explain why the first two are equal even though usually $AB\neq BA$.

Before calculating: what idea do we need?

  1. Product rule: $\det(AB)=\det A\cdot\det B$.
  2. Inverse rule: since $AA^{-1}=I$ and $\det I=1$, $$\det A\cdot\det(A^{-1})=1\quad\Longrightarrow\quad\det(A^{-1})=\frac{1}{\det A}.$$ $A^{-1}$ exists only if $\det A\neq0$.

The key insight: matrices do not commute, but determinants are numbers, and numbers do commute.

1. $\det(AB)$

$$\det(AB)=\det A\cdot\det B=3\cdot(-5)=-15.$$

2. $\det(BA)$

$$\det(BA)=\det B\cdot\det A=(-5)\cdot3=-15.$$

3. $\det(A^{-1}B)$

$\det A=3\neq0$, so $A^{-1}$ exists and $\det(A^{-1})=\tfrac13$. Then

$$\det(A^{-1}B)=\det(A^{-1})\cdot\det B=\frac13\cdot(-5)=-\frac53.$$

4. Why $\det(AB)=\det(BA)$ although $AB\neq BA$

The matrices $AB$ and $BA$ are generally different, but the product rule turns both determinants into a product of the same two numbers, $3$ and $-5$, and multiplication of numbers is commutative.

Geometrically, $\det$ is the volume scaling factor. $AB$ scales volume first by $\det B$, then by $\det A$. $BA$ does it in the opposite order. The shapes may end up different, but the total volume factor is the same: $|3|\cdot|{-5}|=15$, and both flip orientation once.

5. Quick verification with concrete matrices

Take

$$A=\begin{pmatrix}1&1\\0&3\end{pmatrix}\ (\det 3),\qquad B=\begin{pmatrix}1&0\\2&-5\end{pmatrix}\ (\det -5).$$
$$AB=\begin{pmatrix}3&-5\\6&-15\end{pmatrix},\quad BA=\begin{pmatrix}1&1\\2&-13\end{pmatrix}.$$

$AB\neq BA$, but $\det(AB)=-45+30=-15$ and $\det(BA)=-13-2=-15$. ✓

Also $A^{-1}=\tfrac13\begin{pmatrix}3&-1\\0&1\end{pmatrix}$, so $A^{-1}B=\tfrac13\begin{pmatrix}1&5\\2&-5\end{pmatrix}$ and $\det=\tfrac19(-5-10)=-\tfrac{15}{9}=-\tfrac53$. ✓

How I would explain this in class

The determinant of a product is the product of determinants, so $\det(AB)=3\cdot(-5)=-15$ and $\det(BA)=-15$ too. The matrices $AB$ and $BA$ can be different, but their determinants are products of the same two numbers, and numbers commute. Since $\det A\neq0$, $A^{-1}$ exists with determinant $\frac13$, so $\det(A^{-1}B)=-\frac53$.

Exercise 9. Area and the Determinant

The question

The vectors

$$u=\begin{pmatrix}3\\1\end{pmatrix},\qquad v=\begin{pmatrix}1\\4\end{pmatrix}$$

span a parallelogram. Compute its area using a determinant. Then reverse the order of the vectors and explain what changes in the determinant and what does not change in the area.

Before calculating: what idea do we need?

Put the vectors as columns of a matrix. Then

$$\text{area of parallelogram}=\left|\det\begin{pmatrix}u&v\end{pmatrix}\right|.$$

The sign of the determinant carries extra information, which is the orientation:

  • $\det>0$: going from $u$ to $v$ is a counterclockwise turn,
  • $\det<0$: it is a clockwise turn.

Area is always non-negative, which is why we take the absolute value.

1. Compute the determinant

$$\det\begin{pmatrix}3&1\\1&4\end{pmatrix}=3\cdot4-1\cdot1=11.$$

2. The area

$$\text{Area}=|11|=11.$$

The determinant is positive, so $v$ lies counterclockwise from $u$.

3. Reverse the order

$$\det\begin{pmatrix}v&u\end{pmatrix}=\det\begin{pmatrix}1&3\\4&1\end{pmatrix}=1\cdot1-3\cdot4=-11.$$
$\det$Area
$(u,v)$$11$$11$
$(v,u)$$-11$$11$
  • Changes: the sign of the determinant. Swapping two columns multiplies the determinant by $-1$ (Exercise 3), because the orientation is reversed: from $v$ to $u$ is a clockwise turn.
  • Does not change: the area. It is the same parallelogram, so $|\det|$ stays $11$.

4. Why the determinant gives the area

The matrix $\begin{pmatrix}u&v\end{pmatrix}$ sends $e_1\mapsto u$ and $e_2\mapsto v$, so it maps the unit square (area $1$) onto our parallelogram. The determinant is the factor by which the matrix scales areas, so the parallelogram has area $|\det|\cdot1$.

5. Quick verification (geometric)

Put the parallelogram in the rectangle $[0,4]\times[0,5]$ (vertices $0$, $u=(3,1)$, $v=(1,4)$, $u+v=(4,5)$). The rectangle has area $20$. Outside the parallelogram are two triangles with legs $3,1$ (area $1.5$ each), two triangles with legs $1,4$ (area $2$ each), and two $1\times1$ corner squares (area $1$ each):

$$20-2(1.5)-2(2)-2(1)=20-3-4-2=11.\ ✓$$

6. A concrete example

If $v$ were parallel to $u$, e.g. $v=(6,2)$, then $\det=3\cdot2-6\cdot1=0$. The parallelogram collapses into a segment with area $0$, which matches the fact that dependent vectors give $\det=0$.

How I would explain this in class

I put $u$ and $v$ as columns, and the determinant is $3\cdot4-1\cdot1=11$, so the area is $11$. If I swap the vectors, the determinant becomes $-11$, because the orientation flips from counterclockwise to clockwise. The parallelogram is the same, so the area, the absolute value, stays $11$.

Exercise 10. Detecting Dependence

The question

Without a full determinant calculation, explain why

$$\det\begin{pmatrix}1&2&3\\2&4&6\\0&1&5\end{pmatrix}=0.$$

Identify a specific dependence between the rows and connect it with noninvertibility.

Before calculating: what idea do we need?

The determinant is zero exactly when the rows are linearly dependent, i.e. one row can be built from the others. Before computing, it is worth scanning the rows for a simple relation, such as one row being a multiple of another.

Tool: adding a multiple of one row to another does not change the determinant (Exercise 5).

1. Spot the dependence

Compare the first two rows:

$$R_2=(2,4,6)=2\cdot(1,2,3)=2R_1.$$

So the rows satisfy the dependence

$$2R_1-R_2+0\cdot R_3=0.$$

2. Why this forces $\det=0$

Apply $R_2\leftarrow R_2-2R_1$, which does not change the determinant:

$$\begin{pmatrix}1&2&3\\0&0&0\\0&1&5\end{pmatrix}.$$

A matrix with a zero row has determinant $0$: every term of the determinant contains one entry from that row, so every term is zero. Hence

$$\det\begin{pmatrix}1&2&3\\2&4&6\\0&1&5\end{pmatrix}=0.$$

3. Connection with noninvertibility

  • Geometrically: the three rows lie in one plane (only two independent directions), so the "box" they span is flat and has volume $0$.
  • Algebraically: the matrix squashes $\mathbb{R}^3$ into a plane, so some non-zero vector is sent to $0$. Different inputs give the same output, so the map cannot be reversed.

We can find such a vector $x$ with $Ax=0$ from rows 1 and 3 (row 2 gives the same equation as row 1):

$$x+2y+3z=0,\quad y+5z=0\ \Longrightarrow\ y=-5z,\ x=7z.$$

Taking $z=1$: $x=(7,-5,1)^T$.

4. Quick verification

  • $Ax$: row 1: $7-10+3=0$; row 2: $14-20+6=0$; row 3: $0-5+5=0$. So $Ax=0$ with $x\neq0$. ✓
  • Sarrus' rule: $(1\cdot4\cdot5+2\cdot6\cdot0+3\cdot2\cdot1)-(3\cdot4\cdot0+1\cdot6\cdot1+2\cdot2\cdot5)=(20+0+6)-(0+6+20)=0$. ✓

5. A concrete example

Because $A\begin{pmatrix}7\\-5\\1\end{pmatrix}=0$, the system $Ax=b$ can never have a unique solution. If $x_0$ is a solution, then so is $x_0+t(7,-5,1)^T$ for every $t$.

How I would explain this in class

I notice that the second row is exactly twice the first one. Subtracting $2R_1$ from $R_2$ doesn't change the determinant but creates a zero row, so the determinant is $0$. The rows are dependent, the matrix flattens space into a plane, and for example $(7,-5,1)$ is sent to zero. So the matrix cannot be inverted.

Exercise 11. Shortening the Calculation with Row Operations

The question

Compute

$$\det\begin{pmatrix}1&2&3\\1&3&4\\1&4&6\end{pmatrix}$$

by first performing row operations that create as many zeros as possible. State which operations do not change the determinant.

Before calculating: what idea do we need?

Plan before calculating. All three rows start with $1$, so subtracting $R_1$ from the other rows immediately gives zeros in the first column.

Effects of row operations:

  • $R_i\leftarrow R_i+cR_j$ ($i\neq j$): determinant unchanged,
  • swapping two rows: sign changes,
  • scaling a row by $c$: determinant is multiplied by $c$.

We will use only the first type, so the determinant never changes.

1. Clear the first column

$R_2\leftarrow R_2-R_1$: $(1,3,4)-(1,2,3)=(0,1,1)$. Unchanged.

$R_3\leftarrow R_3-R_1$: $(1,4,6)-(1,2,3)=(0,2,3)$. Unchanged.

$$\begin{pmatrix}1&2&3\\0&1&1\\0&2&3\end{pmatrix}.$$

2. Clear below the second pivot

$R_3\leftarrow R_3-2R_2$: $(0,2,3)-(0,2,2)=(0,0,1)$. Unchanged.

$$\begin{pmatrix}1&2&3\\0&1&1\\0&0&1\end{pmatrix}.$$

3. Read off the determinant

The matrix is upper triangular:

$$\det=1\cdot1\cdot1=1.$$

4. Which operations did not change the determinant?

All three: $R_2-R_1$, $R_3-R_1$, $R_3-2R_2$ are all of the type "add a multiple of another row". No swaps or scalings were used, so the original determinant is exactly $1$.

5. Why planning helps

Without row operations, Sarrus' rule needs six triple products. Here, three subtractions with small numbers turn the problem into multiplying three $1$'s. The less arithmetic we do, the fewer chances for mistakes.

6. Quick verification

Cofactor expansion along the first row of the original matrix:

$$1(3\cdot6-4\cdot4)-2(1\cdot6-4\cdot1)+3(1\cdot4-3\cdot1)=1\cdot2-2\cdot2+3\cdot1=2-4+3=1.\ ✓$$

7. A concrete example

$\det=1$ means the matrix preserves volume and orientation. Its inverse also has determinant $1$, and since all entries are integers, the inverse matrix $\frac{1}{\det}\operatorname{adj}(A)$ also has only integer entries.

How I would explain this in class

All rows start with $1$, so I subtract the first row from the others. Then I subtract twice the new second row from the third. These operations don't change the determinant, and I end with a triangular matrix with ones on the diagonal. So the determinant is $1$. A direct expansion confirms it: $2-4+3=1$.

Exercise 12. A Parameter Revealed by a Row Operation

The question

For

$$A(t)=\begin{pmatrix}1&2&3\\2&4&t\\0&1&1\end{pmatrix}$$

find the values of $t$ for which the matrix is not invertible. First perform $R_2\leftarrow R_2-2R_1$ and use the resulting structure. At the end, explain what happens to the rows for the value found.

Before calculating: what idea do we need?

  • The matrix is not invertible exactly when $\det A(t)=0$.
  • $R_2\leftarrow R_2-2R_1$ does not change the determinant, so we may compute the determinant of the simplified matrix instead.
  • The first two entries of $R_2$ are exactly twice those of $R_1$. The row operation will therefore create zeros and isolate the parameter $t$ in a single entry.

1. The row operation

$$R_2-2R_1=(2,4,t)-(2,4,6)=(0,0,t-6).$$
$$A'(t)=\begin{pmatrix}1&2&3\\0&0&t-6\\0&1&1\end{pmatrix},\qquad \det A'(t)=\det A(t).$$

2. Use the structure

Row 2 now has only one possibly non-zero entry. Expanding along row 2, only position $(2,3)$ contributes, with sign $(-1)^{2+3}=-1$:

$$\det A(t)=-(t-6)\cdot\det\begin{pmatrix}1&2\\0&1\end{pmatrix}=-(t-6)\cdot1=6-t.$$

3. Find the forbidden value

$$6-t=0\iff t=6.$$

So $A(t)$ is not invertible only for $t=6$, and invertible for all $t\neq6$.

4. What happens to the rows at $t=6$

For $t=6$ the second row is

$$R_2=(2,4,6)=2\cdot(1,2,3)=2R_1.$$

The second row is just a multiple of the first, so it adds no new information. After the row operation it becomes the zero row. The rows are dependent, the matrix flattens $\mathbb{R}^3$ into a plane, and it cannot be inverted.

5. Quick verification

Direct cofactor expansion along the first row of $A(t)$:

$$\det A(t)=1(4\cdot1-t\cdot1)-2(2\cdot1-t\cdot0)+3(2\cdot1-4\cdot0)=(4-t)-4+6=6-t.\ ✓$$

6. A concrete example

  • $t=7$: $\det=-1\neq0$, invertible.
  • $t=6$: $A(6)\begin{pmatrix}1\\1\\-1\end{pmatrix}=\begin{pmatrix}1+2-3\\2+4-6\\0+1-1\end{pmatrix}=\begin{pmatrix}0\\0\\0\end{pmatrix}$. A non-zero vector is sent to zero, confirming that $A(6)$ is singular.

How I would explain this in class

I subtract twice the first row from the second. This doesn't change the determinant, and the second row becomes $(0,0,t-6)$. Expanding along that row gives $\det=6-t$, so the matrix is singular only for $t=6$. At $t=6$ the second row is exactly twice the first, so the rows are dependent.

Exercise 13. Determinant by Elimination

The question

Compute the determinant of

$$A=\begin{pmatrix}1&2&3\\2&5&7\\1&0&2\end{pmatrix}$$

using elimination, and record the effect of every row operation on the value of the determinant.

Before calculating: what idea do we need?

Elimination turns the matrix into upper triangular form, whose determinant is the product of the diagonal (Exercise 4). We must keep track of how each step changes the determinant:

OperationFactor applied to $\det$
$R_i\leftarrow R_i+cR_j$$1$ (no change)
$R_i\leftrightarrow R_j$$-1$
$R_i\leftarrow cR_i$$c$

Then $\det A=\dfrac{\det(\text{triangular})}{\text{product of all factors}}$.

1. Eliminate the first column

The pivot is $a_{11}=1$.

StepOperationNew rowFactor
1$R_2\leftarrow R_2-2R_1$$(2,5,7)-(2,4,6)=(0,1,1)$$1$
2$R_3\leftarrow R_3-R_1$$(1,0,2)-(1,2,3)=(0,-2,-1)$$1$
$$\begin{pmatrix}1&2&3\\0&1&1\\0&-2&-1\end{pmatrix}.$$

2. Eliminate the second column

The pivot is now $1$ in position $(2,2)$.

StepOperationNew rowFactor
3$R_3\leftarrow R_3+2R_2$$(0,-2,-1)+(0,2,2)=(0,0,1)$$1$
$$U=\begin{pmatrix}1&2&3\\0&1&1\\0&0&1\end{pmatrix}.$$

3. Result

All factors were $1$, so

$$\det A=\det U=1\cdot1\cdot1=1.$$

4. Meaning

  • $\det A=1\neq0$: $A$ is invertible.
  • The pivots $1,1,1$ are all non-zero, which is the elimination version of the same statement: a matrix is invertible exactly when elimination produces a full set of non-zero pivots.
  • Elimination is the practical method for large matrices. It needs roughly $n^3/3$ operations, while cofactor expansion grows like $n!$.

5. Quick verification

Cofactor expansion along the first row:

$$\det A=1(5\cdot2-7\cdot0)-2(2\cdot2-7\cdot1)+3(2\cdot0-5\cdot1)=10-2(-3)+3(-5)=10+6-15=1.\ ✓$$

6. A concrete example

Suppose in step 3 we had swapped $R_2$ and $R_3$ first. Then the factor would be $-1$, the triangular matrix would have a different diagonal, and we would have to divide by $-1$ at the end. The final answer must still be $1$. The bookkeeping protects us from sign errors.

How I would explain this in class

I use the pivot $1$ to clear the first column by subtracting $2R_1$ and $R_1$. Then I use the new pivot $1$ to clear below it by adding $2R_2$. All three operations are "add a multiple of a row", so the determinant never changes. The final triangular matrix has diagonal $1,1,1$, so $\det A=1$, which a cofactor expansion confirms.

Exercise 14. A System of Equations and the Determinant

The question

Consider $Ax=b$ with

$$A=\begin{pmatrix}1&2\\k&4\end{pmatrix}.$$

For which $k$ does the system have exactly one solution for every $b$? For the remaining value, give a right-hand side $b$ with infinitely many solutions and one with no solution.

Before calculating: what idea do we need?

For a square system $Ax=b$:

  • if $\det A\neq0$, $A$ is invertible and $x=A^{-1}b$ is the unique solution for every $b$;
  • if $\det A=0$, the rows are dependent. Then, depending on $b$, there are either infinitely many solutions (the equations agree) or none (the equations contradict each other).

1. Compute the determinant

$$\det A=1\cdot4-2\cdot k=4-2k.$$

2. Unique solution for every $b$

$$4-2k\neq0\iff k\neq2.$$

So for every $k\neq2$ the system has exactly one solution for every $b$, namely

$$x=A^{-1}b=\frac{1}{4-2k}\begin{pmatrix}4&-2\\-k&1\end{pmatrix}b.$$

3. The exceptional value $k=2$

$$A=\begin{pmatrix}1&2\\2&4\end{pmatrix},\qquad R_2=2R_1.$$

The system is

$$\begin{cases}x_1+2x_2=b_1\\2x_1+4x_2=b_2\end{cases}$$

The left side of the second equation is exactly twice the left side of the first. So everything depends on whether $b_2=2b_1$.

Infinitely many solutions: take $b=\begin{pmatrix}1\\2\end{pmatrix}$ (so $b_2=2b_1$). The second equation is just the first one multiplied by $2$, so only $x_1+2x_2=1$ remains:

$$x=\begin{pmatrix}1-2s\\s\end{pmatrix},\qquad s\in\mathbb{R}.$$

Geometrically: both equations describe the same line.

No solution: take $b=\begin{pmatrix}1\\0\end{pmatrix}$. Then

$$x_1+2x_2=1\quad\text{and}\quad 2x_1+4x_2=0\ \Rightarrow\ x_1+2x_2=0.$$

The same expression cannot equal both $1$ and $0$. Geometrically: two parallel lines that never meet.

4. Quick verification

  • Infinitely many: $s=0$ gives $(1,0)$: $1+0=1$, $2+0=2$ ✓. $s=1$ gives $(-1,1)$: $-1+2=1$, $-2+4=2$ ✓.
  • No solution: $R_2-2R_1$ on the augmented matrix $\left(\begin{array}{cc|c}1&2&1\\2&4&0\end{array}\right)$ gives $(0,0\mid-2)$, i.e. $0=-2$. Contradiction ✓.

5. A concrete example of the unique case

For $k=1$, $b=\begin{pmatrix}3\\6\end{pmatrix}$: $\det=2$, and

$$x=\frac12\begin{pmatrix}4&-2\\-1&1\end{pmatrix}\begin{pmatrix}3\\6\end{pmatrix}=\frac12\begin{pmatrix}0\\3\end{pmatrix}=\begin{pmatrix}0\\1.5\end{pmatrix}.$$

Check: $0+2\cdot1.5=3$ ✓, $0+4\cdot1.5=6$ ✓.

How I would explain this in class

The determinant is $4-2k$. If $k\neq2$ it's non-zero, so $A$ is invertible and every $b$ gives exactly one solution. If $k=2$ the second row is twice the first. If $b$ also satisfies $b_2=2b_1$, like $(1,2)$, the two equations are the same line and there are infinitely many solutions. If not, like $(1,0)$, they are parallel lines and there is no solution.

Exercise 15. Combining Determinant Properties

The question

Let $A$ and $B$ be invertible $2\times2$ matrices with

$$\det A=-2,\qquad \det B=3.$$

Without finding the entries, compute

$$\det\left(B^{-1}A^TB\right).$$

State the properties used in order and explain why the factors involving $B$ cancel.

Before calculating: what idea do we need?

We need three properties:

  1. Product rule: $\det(XYZ)=\det X\cdot\det Y\cdot\det Z$.
  2. Inverse rule: $\det(B^{-1})=\dfrac{1}{\det B}$, because $\det B\cdot\det B^{-1}=\det I=1$.
  3. Transpose rule: $\det(A^T)=\det A$.

The idea: the product rule turns a product of matrices (which don't commute) into a product of numbers (which do).

1. Product rule

$$\det\left(B^{-1}A^TB\right)=\det(B^{-1})\cdot\det(A^T)\cdot\det B.$$

2. Inverse rule

$$\det(B^{-1})=\frac{1}{\det B}=\frac13.$$

3. Transpose rule

$$\det(A^T)=\det A=-2.$$

4. Combine

$$\det\left(B^{-1}A^TB\right)=\frac13\cdot(-2)\cdot3=-2.$$

5. Why the factors with $B$ cancel

As matrices, $B^{-1}$ and $B$ are not next to each other, and $A^T$ sits between them. So we cannot just cancel $B^{-1}B=I$ in the matrix product, because in general $B^{-1}A^TB\neq A^T$.

But after taking determinants we have the numbers $\frac{1}{\det B}$ and $\det B$. Numbers commute, so they can be moved together:

$$\frac{1}{\det B}\cdot\det B\cdot\det A^T=1\cdot\det A^T.$$

So the answer does not depend on $B$ at all: for any invertible $B$,

$$\det(B^{-1}MB)=\det M.$$

Meaning: $B^{-1}MB$ is the same transformation as $M$, only described in a different coordinate system (a change of basis). The volume scaling factor is a property of the transformation itself, not of the coordinates, so it is unchanged.

6. Quick verification with concrete matrices

Take $A=\begin{pmatrix}1&0\\0&-2\end{pmatrix}$ ($\det -2$) and $B=\begin{pmatrix}1&1\\0&3\end{pmatrix}$ ($\det 3$). Then $A^T=A$, $B^{-1}=\frac13\begin{pmatrix}3&-1\\0&1\end{pmatrix}$, and

$$A^TB=\begin{pmatrix}1&1\\0&-6\end{pmatrix},\qquad B^{-1}A^TB=\frac13\begin{pmatrix}3&-1\\0&1\end{pmatrix}\begin{pmatrix}1&1\\0&-6\end{pmatrix}=\frac13\begin{pmatrix}3&9\\0&-6\end{pmatrix}=\begin{pmatrix}1&3\\0&-2\end{pmatrix}.$$

This matrix differs from $A^T$, but its determinant is $1\cdot(-2)=-2$. ✓

How I would explain this in class

I use the product rule to split the determinant into three numbers: $\det B^{-1}$, $\det A^T$ and $\det B$. The inverse rule gives $\frac13$, and the transpose rule gives $-2$. As matrices, $B^{-1}$ and $B$ can't cancel because $A^T$ is between them, but as numbers they can, so the answer is $\frac13\cdot(-2)\cdot3=-2$. A change of basis doesn't change the determinant.
